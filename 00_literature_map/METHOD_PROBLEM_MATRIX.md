## 燃料/对象这条横轴

氢/氨：差异扩散、痕量 NOx 和高压工况；烃燃料：详细化学与组分尺度跨度；生物质/煤：材料组成、升温速率与尺度效应；电池：热失控反应可辨识性；金属/固体推进剂：多相与界面。单燃料高精度并不证明跨燃料泛化。

## 贯穿所有分支的比较标准

物理单位一致 → 数据/机理可追溯 → 独立工况切分 → 明确传统基线 → 外推和失效分析 → 不确定度 → 全链路成本 → 后验/实验验证。多方法组合须分别做消融，不能把所有改进归因于新模型名字。
