# 非本领域读者怎样读燃烧 AI 论文

先明确模型回答什么物理问题，再看网络名字。例如“输入温度、压力和当量比，输出点火延迟”是一个明确任务；“用 Transformer 改进燃烧”还没有说明预测目标、可用数据或用途。

## 常见术语

| 术语 | 通俗含义 | 阅读时要追问 |
|---|---|---|
| 详细化学机理 | 用许多组分和反应描述燃料如何反应 | 机理名称、版本、适用燃料、温压范围是否明确？ |
| 化学刚性 | 有些反应很快，有些很慢，数值积分因此昂贵 | 神经网络只替代一步，还是能长时间稳定推进？ |
| 代理模型 surrogate | 用便宜模型近似昂贵计算或实验关系 | 近似的是速率、状态、性质还是整个流场？ |
| 机理缩减 / 降阶 ROM | 用更少变量或反应表示主要行为 | 哪些痕量组分或失效工况被牺牲？ |
| PCA / 潜变量 | 将高维状态压缩为少数坐标 | 压缩误差小，是否也保持反应动力学正确？ |
| DNS | 直接解析很细的湍流尺度，常用于生成研究数据 | 数据是否来自相同机理、网格和边界？ |
| LES / 亚格子闭合 | 解析大涡，用模型补充网格以下的小尺度作用 | 训练目标的滤波方式与实际求解器一致吗？ |
| a priori / a posteriori | 前者离线比较模型，后者把模型放回求解器运行 | 离线准确是否真的带来稳定、正确的 LES？ |
| PINN / 物理信息学习 | 将方程、边界、守恒或物理关系加入学习 | 加入的是哪条约束？只是附加损失，还是严格满足？ |
| 可微求解 | 能对参数或输入计算求解结果的梯度 | 梯度经过了哪些数值步骤？是否检验梯度准确性？ |
| 神经算子 | 学习输入场到输出场之间的映射 | 未见网格、几何、边界和燃料是否真测试过？ |
| CRNN / Neural ODE | 用反应结构或连续动力学组织神经网络 | 发现的参数/结构是否唯一？是否仍需刚性积分器？ |
| 神经网络势 | 从原子构型预测能量和力，用于分子动力学 | 能量/力准确能否转化为正确反应事件和产物？ |
| 主动学习 / 贝叶斯优化 | 选择下一批最有价值的数据或实验 | 与相同预算的随机采样相比，实际节省多少？ |
| UQ / 不确定度 | 描述预测的不确定范围 | 区间覆盖率是否经过独立数据校准？ |
| 当量比 φ | 实际燃料/氧化剂比与化学计量比的比值 | φ<1 为贫燃、φ>1 为富燃；氧化剂组成是什么？ |
| 点火延迟 IDT | 从规定初始状态到规定点火事件的时间 | 用温升阈值、最大 dT/dt，还是 OH 峰定义？ |
| 热释放率 HRR | 单位时间释放的热量；也可能指局部体积源项 | 是 W、W/m³，还是归一化量？不能混用。 |
| LBL / WSGG | 前者逐谱线算辐射，后者用少量灰气近似 | 光谱数据库、混合气、压力与壁面条件一致吗？ |

## 指标不能只看一个数字

- MAE 是绝对误差平均值，必须带单位；RMSE 对少数大误差更敏感。
- R² 接近 1 说明在给定测试集上相对均值基线拟合得好，不证明物理守恒或域外泛化；R² 可以为负。
- log10 MAE 适用于跨数量级的正值，但与原单位 MAE 不同。对数误差 0.1 对应约 10^0.1≈1.26 的倍率，不能直接说成 10% 误差。
- 相对误差在真值接近 0 时会放大，应同时给绝对误差和适当的整体归一化指标。
- 加速比必须说明硬件、容差、批量以及数据搬运/预处理/回退成本。一次推理脚本耗时不是与高保真方法的公平加速比。

## 本库结果应该怎样理解

B01 的 MLP 在 30 个测试工况上的点火延迟中位相对误差约 4.12%。测试是固定机制、固定范围内留出两个温度层的插值；没有证明新燃料、新机理或高压外推也能达到同样误差。

C01 的“2.95%”是 MAE 除以作者参考源项的极差，而相对 L2 约为 8.11%。两者分母不同，并不矛盾；不能把前者转述为“所有辐射误差均低于 3%”。

能运行作者演示，说明特定版本、数据和环境下这条推理链路运行成功。要声称论文指标复现，还必须找到原文目标图表，使用同口径的数据、切分、训练及指标，并解释差异。

## 推荐读一篇论文的顺序

1. 读题名、摘要与结论，确定研究对象和目标量。
2. 看数据来源、单位和训练/测试划分，先判断结果能否公平解释。
3. 找传统方法与简单模型基线，再看新网络的公式与消融。
4. 核对外推、失效案例、不确定度和总计算预算。
5. 最后对照固定代码、数据许可与原文图表，设计最小复现实验。
