# 复现协议与结果解释

## 状态准则

源码下载 → 导入/最小演示 → 原始数据与权重核验 → 同口径基线 → 目标图表复现 → 消融与稳健性，是不同阶段。状态只能按实际证据升级。论文结果对照表应包含原文数值、本地数值、指标定义、数据切分、预算、随机种子和偏差原因。

## 每次实验应记录

- 论文 DOI、目标公式/图/表；原文是否有多个版本。
- 代码提交、数据和机理 SHA-256、单位、预处理、删失/失败样本处理。
- 按轨迹/实验/燃料/装置的训练、验证、测试分组；所有归一化参数只从训练集拟合。
- 软件、设备、精度、随机种子、运行命令、墙钟时间和峰值内存。
- 预测与参考逐样本结果、训练历史、预设指标；多种子统计与失败运行不能选择性隐瞒。
- 修改及其原因，哪些是原文规定，哪些是本库假设，哪些尚未明确。
