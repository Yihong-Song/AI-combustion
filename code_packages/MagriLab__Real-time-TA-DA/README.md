在仓库根目录执行：

```powershell
python tools/fetch_packages.py --package MagriLab__Real-time-TA-DA
```

下载器仅保存源归档和 SHA-256，不执行上游代码。已附归档时可离线核验；归档不含 Git 历史，子模块和 LFS 数据可能不完整。
